ThumbNest Documentation

Enterprise-grade fallback featured images for WordPress. Virtual zero-database overhead, dynamic post-type discovery, and non-destructive batch assignment tools.

✓ WordPress 6.7+ Ready ⚡ PHP 7.4 – 8.3+ 🛡️ 100% Non-Destructive 🚀 Zero Database Bloat

⚡ Quick Start Guide

Get ThumbNest up and running across your entire website in under two minutes:

  1. Install the Plugin

    Go to Plugins > Add New > Upload Plugin in WordPress, upload thumbnest.zip, and activate the plugin.

  2. Select Global Fallback Image

    Navigate to Settings > ThumbNest. Under Global Fallback Image, click Select from Media Library and choose your brand's default placeholder image.

  3. Save and Enjoy

    Click Save Changes. All existing and future posts without a featured image will immediately display the fallback.

🏗️ How It Works

⚡

Virtual Fallback (Default)

Dynamically injects fallback images at runtime via WordPress thumbnail filters. Zero database writes, zero duplicate media attachments.

🛡️

Real Image Priority

ThumbNest strictly respects genuine featured images. Manually assigned post images are never replaced or modified.

🔄

Safe Batch Assigner

Need physical database IDs for legacy feed tools? Use the paginated batch assigner with built-in one-click rollback protection.

💡 Why Virtual Fallback is Better for Performance

On a website with 50,000 posts, traditional plugins duplicate 50,000 rows in wp_postmeta. ThumbNest stores only 1 configuration setting and resolves the fallback in memory in 0.0001s.

🎯 Priority Resolution Hierarchy

Whenever a thumbnail is requested by a theme or widget, ThumbNest resolves the image in this deterministic order:

1. Post has manually assigned Featured Image Returns Real Image
2. Post Type has Custom Fallback Image configured Returns Custom Image
3. Post Type is configured to "Use Global Image" Returns Global Image
4. Post Type fallback is Disabled or No Image Set Returns Empty

🌐 Configuration Guide

From the Settings > ThumbNest menu, customize universal and per-post-type behavior:

Global Fallback Image

Upload a versatile, high-resolution default image (recommended: 1200x630px). It serves as the universal baseline for any post type set to Global.

📝 Post Type Configuration Matrix

ThumbNest dynamically discovers all registered public post types supporting featured images. For each post type, you can choose:

Option Behavior
Use Global Image Inherits the universal fallback image configured at the top.
Use Custom Post-Type Image Allows you to choose an independent fallback (e.g. specialized graphic for News or Pages).
No Fallback (Disabled) Disables fallback logic completely for this post type.

🛡️ Safety & Rollback Guarantee

When physical assignment is run, ThumbNest marks each post with _thumbnest_is_fallback = 1. When clicking Remove Plugin-Assigned Fallbacks, only plugin-assigned images are removed. Real user uploads are never touched.

🧩 Page Builder & Theme Compatibility

Elementor

ThumbNest hooks directly into Elementor's image rendering pipelines. Posts widgets, loop builders, archive cards, and portfolio widgets display fallback thumbnails automatically.

Gutenberg (Block Editor) & Classic Editor

On post editing screens (post.php), ThumbNest ensures the Featured Image sidebar box remains empty if no real image is assigned, preventing author confusion.

🛍️ WooCommerce Compatibility

When WooCommerce support is enabled, catalog products without images will display the configured product fallback image without altering your product image galleries.

💻 Developer Reference & Template Tags

Use these native PHP template tags anywhere in your theme templates:

// 1. Get fallback attachment ID for a post
$image_id = thumbnest_get_fallback_image_id( $post_id );

// 2. Check if a post has an active fallback
if ( thumbnest_has_fallback( $post_id ) ) {
    // Has fallback
}

// 3. Render fallback image HTML markup
thumbnest_the_fallback_image( $post_id, 'medium', array( 'class' => 'my-thumbnail' ) );

🪝 Action & Filter Hooks

Filter: thumbnest_fallback_image_id

Conditionally change fallback images on the fly (e.g. by post category, tag, or author):

add_filter( 'thumbnest_fallback_image_id', function( $fallback_id, $post_id, $post_type ) {
    if ( 'post' === $post_type && has_category( 'interviews', $post_id ) ) {
        return 789; // Attachment ID for Interview category
    }
    return $fallback_id;
}, 10, 3 );

❓ Frequently Asked Questions

Will it overwrite my existing thumbnails?

No. ThumbNest checks for existing manual thumbnails first. If an image exists, ThumbNest does nothing.

What happens when an author adds an image?

The new real featured image immediately takes precedence on the frontend with zero sync required.

Is it compatible with Multisite?

Yes. Each subsite maintains its own independent fallback settings and image selections.

What happens on uninstall?

ThumbNest cleans up all options and transients from the database without deleting your Media Library uploads.
